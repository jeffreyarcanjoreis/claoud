# claoud

Um projeto de prática para aprender o fluxo de contribuição com Git e GitHub.

## Sobre

Este repositório foi criado para praticar abertura de Pull Requests, revisão de código e colaboração em projetos open source.

## Tecnologias

- Git
- GitHub
- Markdown

## Como usar

1. Faça um fork do repositório
2. Clone o fork localmente
3. Crie uma branch para sua alteração
4. Faça o commit e abra um Pull Request

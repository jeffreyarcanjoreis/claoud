# claoud

Um projeto de prática para aprender o fluxo de contribuição com Git e GitHub.

## Sobre

Este repositório foi criado para praticar abertura de Pull Requests, revisão de código e colaboração em projetos open source.

## Tecnologias

- Git
- GitHub
- Markdown

## Como usar

1. Faça um fork do repositório
2. Clone o fork localmente
3. Crie uma branch para sua alteração
4. Faça o commit e abra um Pull Request

## Como contribuir

Contribuições são bem-vindas! Siga os passos abaixo:

1. Abra uma _issue_ descrevendo a melhoria ou bug encontrado
2. Faça um fork e crie uma branch com nome descritivo (ex: `fix/typo-readme`)
3. Faça suas alterações e escreva um commit claro
4. Abra um Pull Request referenciando a issue

Por favor, mantenha o código simples e os commits atômicos.

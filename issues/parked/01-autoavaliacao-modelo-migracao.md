# Modelo Autoavaliação + migração

## Descrição
Cria a entidade que guarda uma autoavaliação enviada a um aluno: a quem pertence, quando foi enviada, quando foi respondida (NULL enquanto pendente), as cinco notas 0–10 do modelo fixo Kairos e a observação livre. Campo sem dado é NULL (regra 6). Suporta os dados por trás de toda a fatia.

## Depende de
nenhuma

## Status
pendente

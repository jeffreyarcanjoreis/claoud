# Coach: sub-aba Autoavaliações + enviar

## Descrição
Na ficha do aluno, uma sub-aba "Autoavaliações" lista as autoavaliações daquele aluno (data de envio, estado pendente/respondida), mais recente primeiro, com estado vazio. Um botão "Enviar autoavaliação" cria uma nova autoavaliação pendente para o aluno e volta à lista mostrando-a; enviar com uma já pendente é recusado com aviso.

## Depende de
02 (serviço)

## Status
pendente
